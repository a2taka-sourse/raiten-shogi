# 禮天将棋（raiten）

**[ブラウザで遊ぶ](https://a2taka-sourse.github.io/raiten-shogi/)**

独自ルール将棋「禮天将棋」をブラウザで試せる対局ページです。JavaScriptに移した合法手生成と、先を読む探索AIで動きます。

## 遊び方

`index.html` を HTTP サーバーで公開します。盤の自分の駒を選び、青いマスへ動かします。持ち駒は盤の下から選べます。先手・後手と AIの強さは「新しい対局を始める」で切り替わります。

## ルールと試作上の扱い

合法手は `reiten_rules.py` の定義を JavaScript に移したものです。持ち駒あり、二卒禁止、打ち卒詰め可、相手陣三段で任意成りです。理は成っても王です。同一局面4回は引き分け、連続王手なら王手側の負けとします。成りの読み方は、NNUE の学習時に A（成ると動きが置き換わる）に確定しました。

## AI

「強い」は `ai.mjs` の探索AIです。α-β探索（反復深化・静止探索・置換表・キラー手と履歴による手の並べ替え・王手の延長）を Web Worker で1手約1秒動かします。評価は駒の価値（持ち駒は少し高め）と位置の補正です。「やさしい」は従来の一手読みの試作AIで、乱数で手をばらつかせます。

探索AIは盤を整数配列にした別実装なので、合法手が `rules.mjs` と一致することを確かめています。

```sh
node test/check_moves.mjs 300 160   # ランダム対局 93,098 局面で rules.mjs と合法手を突き合わせ、不一致 0
node test/match_old.mjs 3 300 A     # 探索AI（1手0.3秒）と従来AIの対局、先後入れ替え
```

従来AIとの対局では、1手0.3秒で全勝でした（6戦6勝）。対局履歴はページを閉じると消えます。ネット対戦機能はありません。

## 関連開発｜やねうら王へのNNUE移植

禮天将棋の別実装で、評価関数をやねうら王へ移植し、アキュムレータの差分更新を実装しました。

- 移植前後を比較し、Fairy-Stockfishの参照実装と9,112局面で評価値が一致することを確認しました。
- 自己対局データで学習したNNUE v6は、v5との比較対局300局で189勝111敗でした。

ここで配布しているブラウザ版は、ルールと対局UIを手軽に試せるJavaScript実装です。
