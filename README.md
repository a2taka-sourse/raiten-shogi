# 禮天将棋・ひとりで対局

ブラウザだけで動く、弱いAIとの対局ページです。サーバー、ログイン、外部ライブラリは使いません。

## 遊び方

`index.html` を HTTP サーバーで公開します。盤の自分の駒を選び、青いマスへ動かします。持ち駒は盤の下から選べます。先手・後手と成りの読み方 A/B は「新しい対局を始める」で切り替わります。

## ルールと試作上の扱い

合法手は `reiten_rules.py` の定義を JavaScript に移したものです。持ち駒あり、二卒禁止、打ち卒詰め可、相手陣三段で任意成りです。理は成っても王です。同一局面4回は引き分け、連続王手なら王手側の負けとします。成りの読み方は A/B を選べます。標準は A です。

AIは一手先の駒得などを見る弱い試作版です。対局履歴はページを閉じると消えます。ネット対戦機能はありません。
