# 禮天将棋（raiten）

**[ブラウザで遊ぶ](https://a2taka-sourse.github.io/raiten-shogi/)**

独自ルール将棋「禮天将棋」をブラウザで試せる対局ページです。JavaScriptに移した合法手生成と、一手先を読む試作AIで動きます。

## 遊び方

`index.html` を HTTP サーバーで公開します。盤の自分の駒を選び、青いマスへ動かします。持ち駒は盤の下から選べます。先手・後手と成りの読み方 A/B は「新しい対局を始める」で切り替わります。

## ルールと試作上の扱い

合法手は `reiten_rules.py` の定義を JavaScript に移したものです。持ち駒あり、二卒禁止、打ち卒詰め可、相手陣三段で任意成りです。理は成っても王です。同一局面4回は引き分け、連続王手なら王手側の負けとします。成りの読み方は A/B を選べます。標準は A です。

AIは一手先の駒得などを見る弱い試作版です。対局履歴はページを閉じると消えます。ネット対戦機能はありません。

## 関連開発｜やねうら王へのNNUE移植

禮天将棋の別実装で、評価関数をやねうら王へ移植し、アキュムレータの差分更新を実装しました。

- 移植前後を比較し、Fairy-Stockfishの参照実装と9,112局面で評価値が一致することを確認しました。
- 自己対局データで学習したNNUE v6は、v5との比較対局300局で189勝111敗でした。

ここで配布しているブラウザ版は、ルールと対局UIを手軽に試せるJavaScript実装です。
